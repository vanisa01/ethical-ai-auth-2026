Why this matters

Code shapes attention, behavior, and thought

Scale & Speed

Web systems now shape beliefs, relationships, and civic life. One ranking decision affects millions. Innovation moves faster than ethical reflection.

Attention Economy

Platforms optimize for engagement through infinite scroll, streaks, and variable rewards. What keeps users engaged is not always what helps them think clearly.

Behavior Engineering

Prediction systems learn from behavior, then optimization systems shape what users do next. Without consent, design patterns influence habit and public discourse.

Fragmented Thinking

Constant interruption loops increase mental switching costs. Shallow engagement replaces deep focus. Developers lose reasoning quality, creativity, and memory depth.

References

Zuboff, 2019. Eyal, 2014. Harris TED Talk, 2016. Newport, 2016. Orlowski, 2020.

A philosophical lens

A question for modern platforms

Aristotle helps us ask one practical question: what kind of habits are our systems training in people?

Habits shape character

If a platform trains constant checking, outrage, or dependency, that is already an ethical outcome.

Design trains habits

Notifications, feeds, and ranking systems do not just serve users. They also teach users how to behave.

Good design supports self-control

Ethical programming should strengthen autonomy, reflection, and informed choice instead of compulsion.

The real question

Are we building systems that help people flourish, or systems that keep them reactive and distracted?

Aristotle, Nicomachean Ethics. Vallor, 2016.

Design & Development

Not just legality, but responsibility

Ethical Programming

  • Respect user autonomy
  • Minimize foreseeable harm
  • Make tradeoffs explicit
  • Protect privacy by default
  • Preserve fairness and dignity

Ethical AI

  • Bias: models replicate unequal data
  • Opacity: users must understand decisions
  • Manipulation: avoid targeting weakness
  • Surveillance: collect only what's needed
  • Governance: human oversight always
Every product decision creates winners, losers, and externalized costs. Repeated defaults become culture, and culture becomes infrastructure.
References

ACM Code of Ethics, 2018. Floridi and Taddeo, 2016. Buolamwini and Gebru, 2018.

Practical approach

Ethical check & code example

Five-question ethical check

  1. Who benefits?
  2. Who might be harmed?
  3. What behavior are we incentivizing?
  4. Can users understand and control?
  5. Could we publicly defend this?

Use in: sprint planning, PR review, design critique, launch readiness.

❌ Unethical: Dark-pattern notifications
def send_notification(user_id, message):
    notification = {
        "priority": "high",
        "sound": True,
        "vibration": True,
    }
    send_time = calculate_when_user_most_vulnerable()
    schedule_notification(notification, send_time)
    track_engagement_for_manipulation(user_id)

Overrides user settings, targets weakness, exploits vulnerability for engagement.

✓ Ethical: Respects user consent
def send_notification(user_id, message):
    prefs = get_user_notification_preferences(user_id)
    if not prefs["notifications_enabled"]:
        return {"status": "skipped"}
    if is_in_user_quiet_hours(user_id):
        return {"status": "deferred"}
    schedule_notification(message, prefs["preferred_send_time"])
    log_notification_sent(user_id, reason="user_request")

Respects consent, quiet hours, user timing, and transparency.

Ethical code is explicit because it encodes values like consent, transparency, and user control.

For web programming students

What we can do now

Design practices

  • Use privacy-preserving defaults
  • Add friction to risky actions and stopping cues to endless flows
  • Explain recommendation logic in user-friendly language
  • Track harm signals, not only growth metrics

Ethical AI Platforms (from industry)

  • Microsoft Responsible AI Toolbox - fairness, interpretability, error analysis
  • IBM watsonx.governance - guardrails for Gen AI and foundation models
  • Google Responsible Generative AI Toolkit - safety, transparency, accountability
  • Amazon SageMaker Clarify - bias detection, explainability
  • Salesforce Einstein Trust Layer - data and compliance guardrails
  • Credo AI - governance platform aligned to regulations (EU AI Act, NIST AI RMF)

Custom solutions

Build domain-specific tools that fill gaps and provide autonomy. Proprietary implementations allow:

  • Fine-tuned governance for your specific context
  • Ownership of ethical frameworks and decisions
  • Direct control over compliance and audit trails
  • Integration with existing systems without vendor lock-in

Closing thoughts

Build systems worth being proud of

Every line of code is a small decision about the world we want to live in. The question is not whether your systems have values — they always do. The question is whether those values are chosen deliberately.
